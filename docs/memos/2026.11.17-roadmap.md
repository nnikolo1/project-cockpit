# Roadmap: open items

Date: 2026-11-17

Open items only, in no committed order. None is a promise.

- **Role separation**: separate identities for Orchestrator and Workers, branch protection, policy workflow installed. Until then protected labels and rule-change flags are hints (see the roles memo).
- **Ranking for agents**: move the ranking out of the page into `logic.py` and serve it, so an unattended Orchestrator takes the same next task the page shows.
- **Module creation**: create the `module:<id>` label from the page, as a possible next step after the config-file approach (ADR 0005).
- **Per-sub-module code metrics**: ask the snapshot producer for sub-module entries; the cockpit already displays them when present.
- **Timeline and log merge**: the timeline already merges GitHub events with git commits and an optional extra timeline file (`--phases`); decide whether anything further is needed once real use shows it.
- **CI status**: show the state of the project's checks next to tasks and modules. Not started; whether it is wanted at all is open.
