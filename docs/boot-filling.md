# Dispatcher (formerly the boot-filling job)

The Dispatcher assigns released tasks to unattended Workers that run in a container. Its behaviour, the Workers, the task folders, the processing log and the settings are defined in [docs/specs/dispatcher-and-workers.md](specs/dispatcher-and-workers.md); this page does not repeat them.

The earlier boot-filling design (ADRs 0014 to 0020) is superseded by that specification.
